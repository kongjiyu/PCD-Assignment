# Academic Performance Management System (APMS)

## Overview
The Academic Performance Management System (APMS) is a comprehensive C-based application designed to manage and calculate student academic performance. This system provides both administrator and student interfaces to handle academic records, calculate GPAs, and track graduation status.

## Features

### Administrator Features
- Secure login system for administrators
- Student registration and management
- Course management for students
- Add and edit course details
- View student academic records
- Calculate and display GPA/CGPA
- Monitor graduation status

### Student Features
- Secure login using student ID and IC
- View personal academic records
- Access GPA and CGPA information
- Check graduation eligibility status

### Academic Features
- GPA calculation per semester
- CGPA calculation across all semesters
- Credit hour tracking
- Grade point conversion
- Graduation status verification
  - Minimum 21 credit hours required
  - Minimum CGPA of 2.00 required

## Technical Details
- Written in C programming language
- Console-based user interface
- Structured data management using arrays and structures
- Secure login system
- Input validation and error handling

## System Requirements
- C compiler
- Windows operating system (for system color commands)
- Console terminal

## Usage
1. Compile the program using a C compiler
2. Run the executable
3. Choose between Administrator or Student mode
4. Follow the on-screen instructions

## Security Features
- Password-protected administrator access
- Student authentication using ID and IC
- Input validation for all data entries

## Data Management
- Student information storage
- Course details management
- Grade tracking
- Academic performance calculation

## Note
This system is designed for educational institutions to manage student academic records and calculate performance metrics efficiently.
